# Roadmap / ideas

Ideas only. Nothing here has been decided.

- Starter templates (e.g. outage email, Roblox Luau system, study notes), loaded into the editor.
- XML-tag output mode (`<role>…</role>`), as Anthropic's docs suggest for Claude.
- "Prompt enhancer" button: copies the draft wrapped in a meta-prompt asking the AI to improve it.
- "Hand it to a human" self-check: a checklist of questions before copying.
- Per-section enable/disable toggle without clearing the content.
- Share a prompt via URL (state encoded in the hash).
